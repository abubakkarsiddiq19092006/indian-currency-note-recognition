
# Indian Currency Note Recognition

A deep learning mini-project that classifies Indian currency note images into seven denomination classes.

## Technologies
- Python
- TensorFlow / Keras
- Convolutional Neural Network (CNN)
- Streamlit
- NumPy and Pillow

## Features
- Upload a currency note image
- Predict the denomination
- Display the model's confidence score

## Current Result
Test accuracy: 61.90% on 42 test images.

## Limitation
This is an educational prototype. Predictions may be incorrect, and it does not verify whether a banknote is genuine.
